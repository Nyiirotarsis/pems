# **App Name**: StockPilot

## Core Features:

- Issue Equipment: Record equipment issued, including date out, quantity out, and equipment type.
- Return Equipment: Record equipment returned, including date in, quantity in, and condition. This form updates the quantities, adding returned items back into stock. 
- Inventory Search: Search and view items in the database based on various criteria, providing a list of matches to the search criteria. For matches, view item details like total quantity available.
- Restock Logging: Log receipt of new stock, including items/qty/received by. Update quantities on hand.
- Request Handling: The tool will manage item requests, checking item availability,  If available the manager is alllowed to make a reservation. if unavailable recommend outsourcing options, with budgetary estimates, using information available online.
- Role-Based Access: Restrict feature access based on user roles (Store Manager, Finance Manager, HR/Admin, CEO, Director, IT).  Roles will include: Capture/Update, Retrieve Captured Items, Issue Out Requested Items, Receive & Update Items, Requesting Roles, Approval Roles.
- Reporting: Generate inventory reports (weekly/monthly).

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and reliability, fitting for inventory management.
- Background color: Light gray (#F0F0F5), providing a neutral backdrop that doesn't distract from the data-rich interface.
- Accent color: Teal (#009688) to highlight key interactive elements and provide a modern, technological feel.
- Headline font: 'Space Grotesk' sans-serif for headlines. Body text: 'Inter' sans-serif for readability in forms and reports.
- Use simple, consistent icons from a library like Material Design Icons to represent different equipment types and actions.
- A clean, organized layout with clear visual hierarchy to facilitate efficient data entry and retrieval. Use of cards and tables for data presentation.
- Subtle animations for loading states and transitions to provide feedback without being distracting.
